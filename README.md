Hangman Game

A classic console-based Hangman game built in Python.

🎮 How It Works
The program randomly picks a word from a predefined list (python, hangman, coding, developer, computer).
Guess one letter at a time — correct guesses reveal the letter's position(s) in the word.
You have 6 incorrect guesses before the game ends.
Win by fully revealing the word before running out of guesses.
▶️ How to Run
bash
python CodeAlpha_python_hangman.py

Requires Python 3.

🛠️ Tech

Pure Python — no external libraries required.
